    solid-router

  • TanStack Router
    tanstack-router/react

Picking a demo animates the real address bar first (vanilla install() in reload mode), then loads the page. While idle, the line above cycles through the demos, rotating its glyph charset, effect (decode / scramble) and speed on every pass. Demos are aliased to src/ — edit the library and refresh.
