glyphnav / core

The framework-agnostic engine behind every adapter: generateFrames() builds the in-between strings and a Player ticks through them. Point that Player at a DOM node instead of history and any text decodes the same way — no URL, no router involved.

Charset, effect and speed (the controls above) drive this — change one and the line re-scrambles; your choices are remembered per page. Type your own text and run it. This page never touches the URL: it is the same core engine, pointed at a <span>.

Reachable from the picker. The same two calls (generateFrames + createPlayer) power the address-bar animation in every other demo.
